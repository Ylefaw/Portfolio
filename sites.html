AquaSite

2024

Lien du GitHub : Site AquaSite

Le Brief : Créer une plateforme de gestion d'aquarium complète, allant de la conception de l'interface jusqu'à l'architecture de la base de données et la logique côté serveur.

La Réalisation : AquaSite a été réalisé avec HTML, CSS, PHP, Symfony, JavaScript et SQL. Ce projet présente une interface responsive, un espace administration sécurisé et une navigation fluide entre les différentes vues (gestion des espèces, capteurs d'eau, etc.).

Processus de pensée

Pour ce projet, mon objectif principal était de simplifier la complexité. La gestion de données environnementales et biologiques peut vite devenir illisible. J'ai donc pensé la structure de la base de données (SQL/Symfony) de manière modulaire, pour ensuite l'afficher via des dashboards épurés (HTML/CSS/JS).

  • Mise en place d'une architecture MVC avec Symfony pour une maintenance facilitée.
  • Design UI axé sur des couleurs marines pour rappeler le domaine de l'aquariophilie.
  • Interactivité via JavaScript pour éviter les rechargements de page inutiles lors des petites modifications de données.

IDBaali

2024

Lien du GitHub : Site ID Baali

Le Brief : Concevoir une plateforme créative attrayante servant de vitrine pour des services professionnels, avec un design moderne et impactant.

La Réalisation : Développement complet de l'interface avec un focus sur les animations et l'expérience utilisateur. L'intégration a été pensée mobile-first pour garantir une parfaite lisibilité sur tous les supports.

Processus de pensée

Le défi majeur d'IDBaali était de capter l'attention instantanément. J'ai choisi des contrastes forts et une typographie audacieuse. J'ai structuré le code CSS pour qu'il soit facilement maintenable, en utilisant des variables et des classes utilitaires. L'interactivité JavaScript a été ajoutée avec parcimonie pour souligner les actions de l'utilisateur sans alourdir la page.
